About the book

A practical introduction to Kali Linux and the fundamentals you need to begin studying cybersecurity, written for readers with limited experience with Linux or security tools who want a clear, structured, hands-on learning path.

You start by installing Kali Linux in Oracle VirtualBox, build the Linux skills security work depends on, learn the networking concepts behind every scan and capture, and then put tools like Nmap, Wireshark, and Gobuster to work in a safe lab. Every chapter has explanations, commands, screenshots, review questions, and a hands-on lab.

Linux foundations

File system, users and permissions, APT, essential commands, and Bash scripting.

Networking

IP addressing, interfaces, DNS, routing, and troubleshooting from the terminal.

Security tools

Nmap, Wireshark, WHOIS, dig, theHarvester, Gobuster, FFUF, Nikto, and more.

Ethics first

Authorization, scope, and isolated practice labs are built into every chapter.
